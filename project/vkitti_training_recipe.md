# Virtual KITTI 2 · fixed development training recipe

The archive feasibility milestone is accepted. Independent SHA-256 reads of all three local archives matched the Implementor census. That census paired 6,378 camera-0 RGB/mask keys across five scenes and three conditions. The inspected development mask passed the palette check. The earlier forward pass used random weights and established only shape and finiteness.

This handoff authorizes one local model development run. Decode only Camera_0, condition clone, scenes 01 and 06 for this run. Verify 717 matched pairs from the archived lists (447 + 270). Leave scene 18 calibration and scenes 02/20 evaluation pixels unopened. Results describe controlled simulated weather on two held-out scenes when eventually measured.

## Model and input

- Torchvision DeepLabV3 with MobileNetV3-Large, `weights=None`, `weights_backbone=None`, 14 logits and no auxiliary head. Initialize from scratch. Use the installed CPU runtime, 4 intra-op threads and 1 inter-op thread with deterministic algorithms enabled. Set Python, NumPy and Torch seeds to 101 before construction and use a seeded Torch generator for training permutations. Report backend and resolved library versions. Stop and report any unsupported deterministic operation.
- Read the publisher `colors.txt` metadata and verify equality for both development scene palettes. Fixed class order, IDs 0–13: Terrain, Sky, Tree, Vegetation, Building, Road, GuardRail, TrafficSign, TrafficLight, Pole, Misc, Truck, Car, Van. Map Undefined to ignore index 255. Reject unknown or ambiguous colors on native masks. `Misc` is a valid category. Verify RGB/mask native dimensions agree.
- Resize RGB with Pillow bilinear to fit a 512×160 canvas (width×height). Use the common scale min(512 / width, 160 / height), round each scaled dimension to nearest integer, minimum 1, then center with the odd remainder on the right/bottom. Fill RGB padding with zero and normalize as float32 RGB divided by 255. Use nearest-neighbor resize on integer mask labels with the same geometry and padding 255. Fail on a malformed image, empty valid training mask after transformation, duplicate key, or missing pair. Record the geometry so logits can later be unpadded and bilinearly restored to native mask resolution before scoring. No random augmentations in this run.

## Fixed training and receipt

- Sort inputs by scene and numeric native frame. Shuffle once per epoch using the seeded generator. Run 6 epochs, nominal batch size 4. Merge a one-image remainder into the prior batch to avoid the pooled BatchNorm singleton and use all pairs. Expect 179 optimizer steps per epoch and 1,074 total. Use CPU float32, AdamW (lr 0.001, betas 0.9/0.999, eps 1e-8, weight decay 0.01), unweighted cross-entropy (mean over valid pixels only, ignore 255), no scheduler, no early stopping, and no selection among checkpoints. Use epoch 6 final weights. Fail on non-finite loss, gradients, or parameters.
- Validate palette/geometry and finite forward/backward on a development batch before the full run. Run the preflight with fresh state, then restart from seed for training. Report measured CPU throughput and elapsed time. If runtime resources prevent finishing, report the blocker and completed steps. Any schedule change needs a new documented decision while the calibration/evaluation scenes remain closed.
- Bind the three archive digests, exact ordered admissible training IDs, preprocessing and resolved settings, runtime versions, training code digest, initialization seed, class pixel counts, epoch losses, and final weights digest. Store weights locally in a tensor-only format such as SafeTensors or NPZ, with explicit architecture and dtype information. If package-artifact hashes aren't available, mark that evidence pending. Save private artifacts under `.local-data/vkitti2/`.
- Report training-only diagnostics (finite loss and weights, per-scene and class support, optional fit-set mIoU with absent classes explicit, and a fit-set majority-class baseline if reporting mIoU). These are model development checks. The next Architect review freezes the calibration score/export and held-out replay protocol before those pixels are used.
